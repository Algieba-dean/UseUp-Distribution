# UseUp Public Distribution & Support Hub

[English](README.en.md) | [简体中文](README.md)

UseUp is a local-first, zero-cloud privacy utility designed to prevent household food waste and streamline expiration date management.

This repository serves as the official public distribution hub, release center, issue tracker, and user community for UseUp. The core application source code is maintained in a private repository, while official installation packages, release notes, and public discussions are consolidated here.

Official Website: https://algieba-dean.github.io/useup_site/

---

## Key Features

1. Visual Red-Amber-Green Priority Alert System: Safe period (Green > 5 days), Expiring soon (Amber 0-5 days), and Expired (Red < 0 days), showing consumption priorities at a glance.
2. Multi-Size Responsive Desktop Widgets: Deeply adapted to Android 12+ dual-track architecture, including 1x1 circular progress, 1x2 compact capsule, 2x2 classic four-quadrant grid, and 2x3 immersive dashboard.
3. Zero-Cloud Local P2P Synchronization: No registration or third-party servers required. Family members pair via QR code within a local Wi-Fi network with millisecond incremental merging.
4. SmartLens Viewfinder & Barcode Scanner: Real-time OCR parsing for printed production dates and shelf-life periods, automatically associating categories and storage templates.
5. Dynamic Theme Workshop: Full-gamut stepless color tuning, custom wallpaper frosted-glass blur, particle starry night effects, and 9-grid frame cropping.
6. Local MCP (Model Context Protocol) Server: Built-in local MCP server supporting direct integration with LLMs like Claude Desktop, Cursor, and DeepSeek.
7. Full Offline Data Backup: Comprehensive Zip archiving and lossless migration for items with multi-image attachments, hardened against path traversal risks.

## Business Model & Supporter Program

UseUp strictly adheres to the principle of local-first privacy and data freedom:

### 100% Core Features Free Forever Promise
All core inventory tracking, expiration notifications, local P2P sync, barcode templates, and multi-size desktop widgets are and will always remain 100% free with no functional lockouts.

### Creator & Independent Developer Support
