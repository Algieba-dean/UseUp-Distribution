# UseUp 公开发行与支持中心 (UseUp Public Distribution Hub)

[简体中文](README.md) | [English](README.en.md)

UseUp 是一款专为家庭食品防浪费与物品保质期管理打造的本地优先、零云端隐私工具。

本项目为 UseUp 官方公开发行、版本发布、问题反馈与用户社区中心。主工程源码维护于私有代码库，所有正式版本安装包、更新日志与公开讨论均在此处集中维护。

官方网站：https://useup.algieba12.cn/

---

## 核心特性一览

1. 可视化红橙绿优先级警示：安全期（绿色 > 5天）、临期警示（橙色 0-5天）、已过期（红色 < 0天），一眼看清优先食用次序。
2. 全新多尺寸桌面小组件：深度适配 Android 12+ 响应式双轨体系，涵盖 1x1 环形电量进度、1x2 紧凑胶囊、2x2 经典四象限网格与 2x3 沉浸看板。
3. 零云端局域网 P2P 同步：无需注册任何账号，无需依赖任何第三方服务器，家庭成员间在 Wi-Fi 局域网内通过二维码对配并毫秒级增量合并。
4. SmartLens 原位取景器与条码识别：毫秒级解析生产日期钢印、喷码与保质期天数，一秒扫码自动关联类别与存储模版。
5. 动态主题工坊：全色域无级调色、自定义壁纸毛玻璃虚化、微粒子动态星空与九宫格边框自由裁切。
6. 局域网轻量 MCP 服务：内置本地 Model Context Protocol (MCP) 服务，支持连接 Claude Desktop、Cursor 与 DeepSeek 等大语言模型。
7. 完整离线数据备份：支持多图附件全量 Zip 归档打包与无损迁移，严防路径遍历，杜绝数据绑架。

## 商业化模式与支持者计划

UseUp 坚定秉持本地优先与数据自由原则：

### 100% 核心功能永久免费承诺
所有的物品记录、保质期到期提醒、局域网 P2P 极速同步、条码识别模版与多尺寸桌面小组件，过去、现在与未来均 100% 免费，绝不设置任何强制收费或功能硬锁死。

### 独立开发者创作者支持
UseUp 坚守本地优先与核心功能完全免费的长期承诺，会员赞助体系正在筹备中。如果您希望支持独立开发，欢迎访问开发者的官方创作者主页：

* 爱发电个人主页：[爱发电官方主页 (https://afdian.com/a/algieba12)](https://afdian.com/a/algieba12)
